## Правила
1. До проверки записать номер коммита и не менять `fall_logic.py`, `config.yaml`, `video_pipeline.py`.
2. Проверку запускает один человек одной командой (`eval/fall_recall.py --set test`), результат записывается как есть.
3. Если после проверки что-то исправили — прежний результат остаётся в README, новый можно получить только на **новой** съёмке.
4. Все числа из «разработки» в README подписаны как «цифры разработки», а не как независимая проверка.
